# 预报与证据规则

最后核对：2026-09-21。涉及模型变更、时效、授权或管控时查询最新官方资料。

通过 [Open-Meteo Forecast API](https://open-meteo.com/en/docs) 按实际坐标请求模式。Open-Meteo 是访问服务，不是额外一个气象模式。

| API model | 机构与模型 | 名义最长时效 |
|---|---|---|
| ecmwf_ifs025 | ECMWF IFS 0.25° | 15 天 |
| gfs_seamless | NOAA GFS Seamless | 16 天 |
| icon_global | DWD ICON Global | 7.5 天 |

以响应内每变量非空时间为准，名义时效不是覆盖保证。参考 [ECMWF API](https://open-meteo.com/en/docs/ecmwf-api)、[DWD API](https://open-meteo.com/en/docs/dwd-api)。风速显式请求 m/s，温度 °C，降水 mm，雪 cm。小时序列可能有服务插值，不表示每小时都有独立模型解算。

请求字段：temperature_2m、apparent_temperature、precipitation、wind_speed_10m、wind_gusts_10m、cloud_cover、snowfall、weather_code。页面展示气温、降水、风速曲线，另有体感和阵风。

- 保留请求坐标、响应网格坐标/高程、原获取时间、URL、模型 ID。
- 所有点有可靠高程才显式传 elevation，否则用服务默认 DEM 校正。不能宣称已完成山脊风场或谷底精确订正。
- 仅复用同坐标、高程、时区缓存。缺测保持 null，不能转零或拿邻近城市替代。
- 失败回退保留旧时间。页面生成时间、API 获取时间、模型起报时间有别；接口未给起报字段时不推断。
- 当前按未来 16 天获取。历史或时效外日期无预报，不能用气候均值冒充。
- 07:30 到达对齐 07:00 小时预报，UI 时刻独立显示，summary.json 保留 sampledAt。降水是 API 定义时段量，不是分钟级瞬时雨强。
- 营地夜间从当日 18:00 至次日 08:00：气温和阵风包含两端共 15 个小时取值；累计降水、降雪用 19:00 至次日 08:00 共 14 个前一小时量。每变量全段覆盖后才汇总，ICON 只覆盖半夜时不能用局部最低温冒充整夜最低温。

## 综合逻辑

### 降水与天气类型

- `precipitation` 为所标时刻**之前一小时**的累计降水，单位 mm，包含雨、阵雨和雪的水当量。19:00 对应 18:00–19:00；00:00 对应前日 23:00–当日 00:00。1 mm 相当于每平方米 1 升水。不等于雨下了一整小时、降雨概率或瞬时雨强。
- `weather_code` 是 API 所标时刻的天气类型，按 [官方 WMO 编码表](https://open-meteo.com/en/docs) 解释。61/63/65 显示小雨/中雨/大雨，80/81/82 显示弱/中等/强阵雨；51/53/55 是毛毛雨，不能全部写成小雨。雪、冻雨、雷暴独立展示。
- 类型名称不从小时累计量反推、不对类型编码求均值或中位数。各模型分别显示，有分歧则并列，不按多数票掩盖雨雪差异。类型与降水量统计时段不同，允许“晴 + 前一小时有降水”。
- 旧缓存没有 weather_code 或遇到未知编码，显示类型待确认，保持已有数值；只有 snowfall 明确为正时，允许提示“有降雪信号”。不凭气温猜测雨雪，不把缺测作晴天或零降水。
- “阵雨”是方式，不是小于小雨的雨量等级。[国内 24 小时降雨等级](https://scey.gov.cn/public/6598871/11597217.html) 的小雨 0.1–9.9、中雨 10–24.9、大雨 25–49.9 mm 等只作口径参考，不能用于小时量，也不能把小时量简单乘以 24。页面雨势名称采用模型编码，不能宣称等于我国日雨量等级。
- 冰雹编码仅在接口确实返回时展示；该服务的雷暴伴冰雹预报支持范围为中欧，不能宣称已为四川接入冰雹预报。

### 数值汇总

气温、体感、降水取可用模型中位数，阵风取最高值。开关只影响曲线，汇总保留全部可用模型。无历史验证权重，不造“精准加权”。spread 是分歧，不是置信区间或概率。

同一物理模型经不同商家转发不能重复计票。三个模式也不是完全独立样本。仅一个模型覆盖时明确说明，不称多模型一致。

超过 7 天只称远期趋势，不承诺摄影窗口、无雷暴或安全翻垭口。临近出发可按需增加当地官方预警、站点、雷达，单独标注类型与覆盖，不伪装成已接入第四模式。
